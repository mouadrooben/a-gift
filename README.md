🌼 **Flower Catch** 🐈
=====================

A lovely, colorful browser game where you help a cute cat catch falling flowers!

## Features 🎮

✨ **Beautiful Purple & Colorful Theme**
- Vibrant gradient backgrounds
- Colorful falling flowers
- Cute animated cat character

📱 **Fully Responsive**
- Works on desktop with keyboard/mouse controls
- Works on mobile with touch controls and buttons
- Automatically adjusts to any screen size

🎮 **Game Controls**

**Desktop:**
- `← → Arrow Keys` or `A/D` to move the cat
- Move your `Mouse` to control the cat

**Mobile:**
- Tap `LEFT/RIGHT` buttons
- Drag across the screen to move the cat

## How to Play 🎯

1. Help the cat catch falling flowers
2. Different colored flowers give different points:
   - 💜 Purple = 50 points
   - Light Purple = 40 points
   - Pink = 30 points
   - Hot Pink = 35 points
   - Yellow = 25 points
   - Orange = 25 points
   - Blue = 30 points
   - Mint = 25 points

3. Don't miss any flowers - you have 3 lives!
4. Collect 10 flowers to level up and increase difficulty
5. Try to get the highest score!

## Files 📁

- `index.html` - Game structure
- `styles.css` - Beautiful styling and animations
- `script.js` - Game logic and mechanics
- `README.md` - This file

## How to Run 🚀

1. Open `index.html` in a web browser
2. Click "Start Game" button
3. Play and have fun!
